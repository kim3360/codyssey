# 문제7 자비스가 필요해!

이미지의 요구사항에 맞춰 마이크 음성을 녹음해 파일로 저장하는 코드를 작성했습니다.

## 파일 구성

- `jarvis.py`: 녹음 기능 구현 코드
- `README.md`: 요구사항 반영 내용 및 실행 방법

## 수행과제 반영

- 시스템 마이크를 사용해 음성을 녹음합니다.
- 녹음 파일은 실행 폴더의 `records` 폴더에 저장합니다.
- 파일명은 녹음 날짜/시간 기준 `년월일-시간초` 형식으로 저장합니다.
  - 예: `20260505-214512.wav`
- 실행 코드는 `jarvis.py` 파일에 작성되어 있습니다.

## 제약사항 반영

- 표준 라이브러리: `datetime`, `os`, `wave`
- 마이크 입력 부분은 외부 라이브러리 `pyaudio` 사용
  - 문제 요구사항의 “마이크 인식/녹음 부분 외부 라이브러리 사용 가능” 반영
- 함수/메서드 이름은 snake_case 사용 (`record_voice`, `main`)
- 오류 상황(예: `pyaudio` 미설치)에 대한 예외 메시지 포함

## 보너스 과제 반영

- 특정 길이 녹음을 위한 매개변수 제공
  - `record_voice(duration_seconds=5)`
  - 원하는 길이(초)로 조정 가능

## 실행 방법

1. `pyaudio` 설치

```bash
pip install pyaudio
```

2. 프로그램 실행

```bash
python3 jarvis.py
```

3. 실행 후 `records` 폴더에 `.wav` 파일이 생성됩니다.
