# 문제 6 — 미션 컴퓨터 리턴즈

## 스토리

화성 기지에 돔을 새로 만들어 연결하고 기지를 보강하고 나니 드디어 우주복을 벗을 수 있었다.

우주복을 벗고 나니 한결 마음의 여유가 생긴다. 하지만 여전히 가장 큰 문제가 남아 있다. 미션 컴퓨터가 지금 상태로는 제대로 작동하지 못한다는 점이다. 한송희 박사는 미션 컴퓨터의 메뉴를 구성하고, 앞으로 생존에 필요한 기능을 하나씩 추가하면서 화성을 탈출할 수 있는 실마리를 만들어 가야 한다고 생각했다.

그러기 위해서는 먼저 화성 기지에 남은 센서로 환경 값을 읽어 들이고 출력하는 기능을 추가해야 한다. 그리고 실제 센서를 만들기 전에 **더미 센서(dummy sensor)**부터 만들어 테스트를 시작해야 한다.

---

## 수행 과제

### 1. `DummySensor` 클래스

- 더미 센서에 해당하는 클래스를 만든다. 클래스 이름은 **`DummySensor`**로 정의한다.
- 멤버로 **`env_values`** 사전(dict)을 둔다. 다음 키가 있어야 한다.

| 항목 | 키 이름 |
|------|---------|
| 화성 기지 내부 온도 | `mars_base_internal_temperature` |
| 화성 기지 외부 온도 | `mars_base_external_temperature` |
| 화성 기지 내부 습도 | `mars_base_internal_humidity` |
| 화성 기지 외부 광량 | `mars_base_external_illuminance` |
| 화성 기지 내부 이산화탄소 농도 | `mars_base_internal_co2` |
| 화성 기지 내부 산소 농도 | `mars_base_internal_oxygen` |

- 테스트용 객체이므로 데이터는 **랜덤**으로 생성한다.

### 2. `set_env()` 메서드

- `random`으로 **아래 범위** 안의 값을 생성해 `env_values`에 채운다.

| 항목 | 범위 |
|------|------|
| 화성 기지 내부 온도 | 18 ~ 30 °C |
| 화성 기지 외부 온도 | 0 ~ 21 °C |
| 화성 기지 내부 습도 | 50 ~ 60 % |
| 화성 기지 외부 광량 | 500 ~ 715 W/m² |
| 화성 기지 내부 이산화탄소 농도 | 0.02 ~ 0.1 % |
| 화성 기지 내부 산소 농도 | 4 ~ 7 % |

### 3. `get_env()` 메서드

- **`env_values`**를 반환(return)한다.

### 4. 실행 및 제출

- `DummySensor`를 **`ds`**라는 이름으로 인스턴스화한다.
- `set_env()`와 `get_env()`를 순서대로 호출해 값을 확인한다.
- 전체 코드를 **`mars_mission_computer.py`** 파일로 저장한다.

**학습 시간:** 5

---

## 개발 환경

- Python **3.x**
- Python **표준 라이브러리만** 사용한다. 별도 패키지·서드파티 라이브러리는 사용하지 않는다. (**`random`은 사용 가능**)
- [PEP 8](https://peps.python.org/pep-0008/) 코드 스타일을 따른다.
- 문자열은 기본적으로 **작은따옴표(`'`)**를 쓴다. 문자열 안에 `'`가 필요한 등 부득한 경우에만 큰따옴표(`"`)를 쓴다.
- 대입문은 `=` 앞뒤에 공백을 둔다. (예: `foo = (0,)`)
- 들여쓰기는 **공백**을 기본으로 한다.

---

## 제약 조건

- 표준 라이브러리만 사용한다. **`random`은 예외로 사용 가능**하다.
- PEP 8을 준수한다.
- **경고 없이** 모든 코드가 실행되어야 한다.
